More identifiers (optional — each one stops strangers being flagged as you)

Aadhaar and PAN are checked for a valid checksum, then searched only against leak dumps held on this machine. No public profile displays them, so they cannot identify a web account — and they are never stored or sent anywhere in the clear.

No Indian people-search site publishes an API to check whether it holds you, and probing them would breach their terms — so nothing is guessed. You know which services you signed up for, and that knowledge is itself valid grounds for a DPDP s.12 request.

The password never leaves this machine: only the first 5 characters of its SHA-1 are sent, and the match is done locally.
